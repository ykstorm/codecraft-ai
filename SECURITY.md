# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Email raolakshyaraj@gmail.com with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

Do NOT open a public GitHub issue for security vulnerabilities. We aim to respond within 48 hours and publish a fix in the next minor release.
